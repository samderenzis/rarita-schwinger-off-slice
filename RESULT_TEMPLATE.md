# Result template

Copy this for every reported outcome, into `results/` or a note. Fill in every field. Write "not checked" rather than leaving a field out.

```
## Result: <short title>   (date: YYYY-MM-DD)

Outcome type: POSITIVE (constrained Jordan chain found)
            | NEGATIVE (tested crossing(s) exactly semisimple)
            | NO CROSSING FOUND (search did not locate a real crossing)

Parameter point
  λ = …    m = …    q = …    (q / (λ√(2/3)·m) = 1 + ε, ε = …)
  b₁ = …   b₂ = …   π′ = …
  Exact or approximate: …

Crossing
  Covector ξ (exact algebraic numbers): …
  Eigenvalue r: …
  Number field used, with its defining polynomial: …

Constrained structure (on ker L(ξ))
  dim ker L(ξ) = …
  Ranks of (P − r)^j restricted to ker L, j = 1, 2, …: …
  Chain v → w (if positive), with exact entries: …   file: …
  Engines: …   Cross-checked in a second engine: yes / no

Hypotheses re-checked at this point (the paper's argument needs all four)
  det S⁰ ≠ 0: …
  Reduction identities with q free: …
  Coercivity on some ball: …
  Curved-symbol identification: …

Reproduce
  Command: …
  Input and output files, with SHA-256: …
  Python and package versions: …

What this does NOT establish
  - Persistence on an open set of parameters (needs its own proof).
  - Which of existence, uniqueness or the bound fails.
  - Anything about physics.
  - (NEGATIVE) Absence of defects at other crossings, other eigenvalues or other directions.
  - (NO CROSSING FOUND) That no real crossing exists nearby (needs an exact exclusion argument).

Review status: AI-checked only / … (state plainly)
```
