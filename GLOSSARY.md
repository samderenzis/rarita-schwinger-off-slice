# Glossary

These are working definitions, written for orientation. The precise definitions are in the parent [paper](https://github.com/samderenzis/rarita-schwinger-well-posedness/blob/main/paper/main.pdf).

- **Pauli slice.** The set of parameters where the charge is tied to the Pauli coupling and the mass: q = λ√(2/3)·m. The published witness lies on it. "Off the slice" means q is chosen independently.
- **Witness.** The exact data at one parameter point and one covector that the published theorem rests on. It is a Jordan chain at the real eigenvalue r = 101/99, at ξ* = (20/99, 0, 1, 0).
- **Principal symbol, P(ξ).** The matrix that governs the highest-derivative part of the reduced evolution equation in the direction ξ. Its eigenvalues are the characteristic speeds.
- **Constraint symbol, L(ξ).** The principal part of the constraint the field must satisfy. **ker L(ξ)** is the set of directions allowed by the constraint.
- **Constrained symbol.** P restricted to ker L. The published obstruction lives here, not in P alone.
- **Characteristic speed.** An eigenvalue of P(ξ). This is a property of the symbol, **not** a signal speed.
- **Crossing.** A covector where two characteristic speeds meet, giving a repeated eigenvalue. Defects can only occur at crossings.
- **Semisimple.** A repeated eigenvalue that still has a full set of eigenvectors, so there is no Jordan block. A loss-free bound is not ruled out by this mechanism.
- **Defect / Jordan block / Jordan chain.** A repeated eigenvalue that lacks a full set of eigenvectors. A **Jordan chain** v → w is the explicit evidence: (P − r)w = v and (P − r)v = 0, inside ker L. A chain like this rules out the resolvent bound that a loss-free L² estimate would need.
- **Certificate.** Exact data (numbers in a stated number field, and the chain vectors) that anyone can check with plain arithmetic, without trusting the search that found them.
- **Number field.** The exact arithmetic setting for a computation, for example ℚ(i) for the published witness. Off the slice, crossings may need fields generated by nested square roots.
- **Pointwise vs family result.** A pointwise result holds at one parameter point. A family result needs a parametrised argument. Persistence on an open set of parameters needs its own proof.

## Terms added with the off-slice results (2026-11-25)

### The off-slice family
- **ε, q_slice.** The off-slice family is parametrised as q = (1 + ε)·q_slice, where q_slice = λ√(2/3)·m. Here ε = 0 is the slice, and m, λ, b₁, b₂ keep the parent witness values unless stated otherwise. The scripts also use η = 35736·(q − q_slice), so η² = 2450894·ε².
- **Ray 1, ray 2.** The covector families along which crossings are tracked: ξ = (s, 0, 1, 0) and ξ′ = (1, 0, t, 0). Rotations within each sphere factor carry the results to related covectors (`scripts/m2_rotation_invariance.py`).
- **Light eigenvalue, r = |ξ|.** The eigenvalue of P on ker L coming from the factor (x² − |ξ|²), which is (x² − s² − 1) on ray 1. Off the crossings it is semisimple, with multiplicity 4 on ker L. The Jordan results in this repository are all about this eigenvalue.
- **Split crossings; ε_L and ε_U.** Off the slice, the parent crossing splits into a **lower** and an **upper** crossing.
  - The lower one exists exactly for 0 < ε² < ε_L² = (34404 − 12√5659689)/823, so ε_L ≈ 2.6674.
  - The upper one exists exactly for 0 < ε² < ε_U² = (58228 − 20√1645345)/823, so ε_U ≈ 6.2912.
- **Triple crossing.** A covector where the light eigenvalue meets two other sheets at once, giving algebraic multiplicity 6 on ker L instead of 5. On ray 1 there are four real triple crossings: ε² ≈ 102.677 and 108.096 (ε ≈ 10.133 and 10.397), each with both signs of η. They lie outside the split-crossing ranges.

### Reduction and constraint terms
- **Elimination matrix S⁰; det S⁰ ≠ 0.** The coefficient matrix used to solve the constraints for the time component of the field. The reduced system, and every result here, needs det S⁰ ≠ 0 (also written d₀ ≠ 0). At the witness m, λ, b this holds for |ε| < 8.82 (`results/step2_reduction_q_free_2026-11-22.txt`). The triple crossings lie outside that range, so det S⁰ ≠ 0 is certified at each of those points separately.
- **π′.** The parameter of the family of constraint additions to the evolution system (CONVENTIONS.md). The parent paper shows the Jordan obstruction does not depend on π′. Some checks here are done at π′ = 1/2 and are labelled so.

### Jordan structure and how it is certified
- **Algebraic and geometric multiplicity (alg, geo).** alg is how many times r is a root of the characteristic polynomial of P on ker L. geo is the dimension of its eigenspace inside ker L. If geo < alg there is at least one Jordan block. This repository certifies the two numbers separately: alg from exact polynomial identities, geo from exact rank bounds.
- **Jordan type, J₂ ⊕ 3J₁.** The list of Jordan blocks at an eigenvalue. Jₖ is one block of size k, and 3J₁ means three blocks of size 1, which are plain eigenvectors.
  - J₂ ⊕ 3J₁ has one size-2 block and three plain eigenvectors (alg 5, geo 4). This is the type at the split crossings.
  - J₃ ⊕ 3J₁ has one size-3 block (alg 6, geo 4). This is the type at the triple crossings.
  - To tell J₃ ⊕ 3J₁ from the other alg 6, geo 4 type, 2J₂ ⊕ 2J₁, one needs the rank of (P − r)².
- **Box certificate, rank bound.** How a statement is proved for every ε in an interval, rather than at sample points.
  - The interval is covered by small boxes.
  - On each box, an exact rational matrix C satisfies ‖C·A − I‖∞ < 1 for a fixed minor A of the relevant matrix. That forces A to stay invertible on the whole box, so the rank stays at least the size of A.
  - Exact Sturm counts show the crossing really lies inside each box.
- **Second engine.** An independent re-check written in plain Python fractions, with no SymPy, such as the `verify_*_fractions.py` scripts. It guards against errors in one computer-algebra system. It is still written in this project from the same formulas, so it is **not** independent replication.

### Evidence labels and reproduction
- **Evidence labels.** Working labels as used in `audit/README.md`:
  - **ESTABLISHED:** exact proof or certificate in this repository.
  - **REPRODUCED:** re-derived in a second engine.
  - **SUPPORTED:** argued by proof reading, without an exact check.
  - **EXPLORATORY:** numerical or unfinished; a lead, not a result.
  - **INCOMPLETE:** known gaps remain.
  - **CERTIFIED EXTERNALLY:** certified by an engine that is not in this repository, with its certificate files included here. It cannot be re-derived from this repository.

  None of these labels means peer reviewed or human verified.
- **Owner reproduction.** A re-run of every script that has a committed log, on the owner's own computer, comparing each new output with the committed one (`results/OWNER_REPRODUCTION_2026-11-25.md`). The outcomes are:
  - **MATCH:** identical, ignoring dates, timings, tool versions and output paths.
  - **MATCH-EOL:** identical except Windows line endings in regenerated JSON.
  - **MATCH-KNOWN:** only a recorded, explained difference.

  A full match shows the software is reproducible, not that the mathematics is correct.
